# Lesson 04: Physical and Chemical Properties

> **Estimated Review Time:** 10–15 minutes

# Learning Objectives

- Define physical and chemical properties.
- Distinguish between them.
- Identify examples from daily life.

# Why This Topic Matters

Properties help us identify substances, compare them, and predict how they behave.

# Building the Intuition

If you can observe a property **without changing the substance**, it is usually a **physical property**.

If observing the property requires a **chemical reaction**, it is a **chemical property**.

# Physical Properties

Examples:
- Colour
- Density
- Melting point
- Boiling point
- Solubility
- Conductivity
- Hardness

# Chemical Properties

Examples:
- Flammability
- Rusting
- Reactivity with acids
- Reactivity with water
- Corrosion resistance

# Comparison

| Physical Property | Chemical Property |
|---|---|
| No new substance forms | New substance forms |
| Observed without chemical change | Observed during chemical reaction |

# Common Misconceptions

- Melting is **not** a chemical property.
- Boiling does **not** produce a new substance.
- Rusting is **not** a physical property.

# Summary

Physical properties describe a substance without changing it.

Chemical properties describe how it behaves during chemical reactions.
