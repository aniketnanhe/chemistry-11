# Lesson 07: SI Units

> **Estimated Review Time:** 10–15 minutes

# Learning Objectives

- Understand the need for a standard system of units.
- Identify the seven SI base units.
- Use common SI prefixes correctly.
- Convert between units.

# Why This Topic Matters

Imagine one scientist measures length in metres while another uses feet. Comparing results would be confusing. The International System of Units (SI) provides a common language for measurements worldwide.

# Building the Intuition

A number without a unit is incomplete.

Saying "The table is 2" is meaningless.

Saying "The table is 2 metres long" conveys complete information.

# SI Base Units

| Physical Quantity | SI Unit | Symbol |
|---|---|---|
| Length | metre | m |
| Mass | kilogram | kg |
| Time | second | s |
| Electric current | ampere | A |
| Temperature | kelvin | K |
| Amount of substance | mole | mol |
| Luminous intensity | candela | cd |

# SI Prefixes

| Prefix | Symbol | Factor |
|---|---|---|
| kilo | k | 10³ |
| centi | c | 10⁻² |
| milli | m | 10⁻³ |
| micro | μ | 10⁻⁶ |
| nano | n | 10⁻⁹ |

# Common Mistakes

- Confusing mass (kg) with weight (N).
- Writing unit symbols incorrectly (e.g., K not °K).

# Think About It

1. Why is a universal system of units necessary?
2. Why is kilogram, not gram, the SI base unit for mass?

# Summary

SI units ensure consistency, accuracy, and clear communication in science.

# Retrieval Practice

1. Name the seven SI base units.
2. What does the prefix milli mean?
3. Convert 2.5 km into metres.
